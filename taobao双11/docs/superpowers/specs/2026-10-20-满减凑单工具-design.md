# 淘宝双11 满减凑单工具 — 设计文档

日期：2026-10-20
状态：v1（用户未参与实时评审，按最合理默认实现，欢迎随时推翻）

## 背景与目标

用户在李佳琦直播间等淘宝双11场景凑满减时，规则多、门槛多，手工算"还差多少、
加什么凑单最划算"非常折磨。目标：做一个**特别简单**的个人工具，输入购物车里
想要的商品，立刻看清各满减池的优惠进度，并给出"加什么凑单品最划算"的答案。

成功标准：
1. 双击打开即用，无安装、无网络依赖；
2. 输入商品后 1 秒内看清：每个池已省多少、还差多少到下一档；
3. 凑单助手给出明确的组合建议（刚好越线 / 不越线最接近）；
4. 算钱准确（分为单位整数运算，不出现浮点误差）。

## 范围（v1）

**做：**
- 满减池：支持任意多个池，每池规则为"每满 X 元减 Y 元"（默认预置 每300减50；
  可再加池，如 每200减30）。商品按池归属，满减不跨池。
- 商品清单：名称、价格、所属池、数量；增删改；localStorage 自动保存。
- 实时结算：每池小计 / 已享满减 / 距下一档差距；整单原价合计 / 总共已省 / 实付。
- 整单券（可选）：满 X 减 Y，按满减后总价判门槛（v1 固定此口径，界面注明）；
  支持多张，逐张展示"已达标 / 差多少"。
- 凑单助手：对指定池，从候选凑单品（预置常见价位清单 + 用户自定义）中，
  用子集和 DP 求出：① 总价≥差距且溢出最小的组合；② 总价≤差距且最接近的组合。
  各给最多 3 组，并标注"这组凑单品实付 = 组合价 − 新增满减"。
- 分享：把当前清单编码进 URL hash，复制链接即可在手机上打开同一份清单。

**不做（记录为 v2 候选）：**
- 自动抓取购物车/商品价格（无公开接口，v1 手动输入价格）；
- 官方立减/88VIP 折扣的建模（用户直接输入折后价即可参与满减计算）；
- 预售定金/尾款的拆分计算；
- "想买清单超预算时的取舍最优解"（目标函数不明确，等真实需求）。

## 形态与技术决策

- **单文件 HTML**（`凑满减工具.html`）：免安装、可 AirDrop 到手机、离线可用。
- 源码结构（保证可测试）：
  - `core.js`：纯计算逻辑（门槛数学、子集和求解器），UMD 风格同时兼容
    node（测试）与浏览器；金额一律用"分"（整数）运算。
  - `core.test.js`：`node --test` 单元测试。
  - `index.template.html`：页面模板，含 `/*__CORE__*/` 占位标记。
  - `build.py`：把 core.js 内联进模板，产出最终单文件。
  - `凑满减工具.html`：构建产物（交付物，入库）。
- UI：移动优先、中文、系统字体、零依赖；localStorage 自动持久化，一键清空。

## 核心算法

- 每池折扣：`tiers = floor(subtotal / X)`，`discount = tiers * Y`；
  `gap = X - subtotal % X`（恰为整数倍时 gap 为 0，下一档需再加 X）。
- 凑单求解（`bestFillers(gap, candidates)`）：候选={名称,价格(分),可选数量上限}。
  DP 可达和集合（上界 gap+最大候选价），在 `[gap, gap+上界]` 中取溢出最小的
  前若干个和、在 `[0, gap)` 中取最大的前若干个和，回溯重构组合（偏好件数少）。
  无解（候选全为空/全部过大）时如实返回空。

## 错误处理与边界

- 价格输入支持 `89` / `89.5` / `89.99`，转分四舍五入；负数/非法输入拒绝并提示。
- 删除池时其下商品一并移除（弹确认）。
- localStorage 损坏/为空时回退到初始示例；URL hash 解码失败时忽略并提示。
