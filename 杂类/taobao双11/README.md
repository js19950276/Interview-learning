# 双11凑满减小助手

看李佳琦直播间凑满减不再折磨：把想要的商品价格丢进来，工具立刻告诉你
每个满减池**已省多少、还差多少到下一档**，并从候选凑单品里**算出最划算的凑单组合**（溢出最小的越线方案 + 不越线最接近的方案）。

## 怎么用（不用安装）

- **Mac 上**：双击打开 `凑满减工具.html` 就能用。
- **手机上**：把这个文件 AirDrop 给自己（或用页面底部「复制分享链接」），用 Safari/Chrome 打开。数据自动存在本机浏览器里，下次打开还在。

三步上手：

1. **满减规则**：默认每 300 减 50，按直播间实际规则改（可加多个池，如每 200 减 30）。
2. **购物清单**：把想要的商品名和到手价（券后/折后价）填进去。
3. **凑单助手**：点「帮我凑」，从候选凑单品里挑组合；价格可按实际改，也能自己加。看中哪个方案点「加入清单」即可。

整单券（如满 1000 减 120 的官方消费券）在「整单券」区添加，门槛按满减后总价计算。

## 开发

```
node --test        # 核心算法单元测试（20 条）
python3 build.py   # 把 core.js 内联进模板，重新生成 凑满减工具.html
```

文件结构：

| 文件 | 作用 |
| --- | --- |
| `凑满减工具.html` | **交付物**：单文件工具，免安装离线可用 |
| `core.js` | 核心算法（分整数运算、子集和 DP 凑单求解），node/浏览器双端 |
| `core.test.js` | 单元测试 |
| `index.template.html` | 页面模板（含 UI 与交互） |
| `build.py` | 构建脚本 |
| `docs/superpowers/specs/` | 设计文档 |

设计取舍与 v2 候选（自动抓购物车价格、立减建模、预算取舍最优解等）见
`docs/superpowers/specs/2026-10-20-满减凑单工具-design.md`。
