# Steam 式对局界面与原创工业贴图设计

## 结论

采用已确认的 A 方案：借鉴 Steam 版《Brass: Birmingham》的对局信息架构，用原创的维多利亚工业视觉素材重做权威对局界面。地图继续作为主视觉；顶部状态、左右信息轨、底部手牌和行动流程压缩到边缘。视觉采用已确认的中等纹理密度：锻铁、旧黄铜、深木、羊皮纸、煤黑卡背和克制的绿/红状态光效。

本次只重做对局界面，不改首页、附近房间、房间大厅和设置页。实现保留当前中文、真实规则投影、贸易商、路线时代表达、产业建造反馈、当前玩家提示和双模拟器联机行为。

## 参考边界

- Steam 版仅用于观察信息层级、密度、面板位置和操作反馈。
- 不打包、不描摹、不切取官方地图、卡牌、人物、图标、纹章或 UI 贴图。
- 项目使用独立生成并人工筛选的原创材质和产业徽章；既有地图背景继续保留。
- 不把生成式图片中的文字直接用于产品。所有中文、数字和状态都由 SwiftUI/SpriteKit 实时渲染，保证清晰和可访问。

## 视觉系统

### 材质

- **外框与信息轨：** 深色锻铁，轻微磨损与铆钉；避免大面积花纹。
- **强调件：** 旧黄铜，仅用于边缘、选中态、当前回合和主要操作。
- **内容底板：** 深胡桃木或煤黑皮革，降低透明毛玻璃造成的灰色塑料感。
- **标签：** 低饱和羊皮纸小牌，用于城市名、阶段名和短说明，不承载长段信息。
- **状态：** 合法目标使用柔和绿光和清晰描边；不可用使用暗化与克制红边；当前选择使用黄铜高光。

### 原创资产清单

最终素材进入 `Assets.xcassets/MatchChrome`，按组件分别输出，不使用一张整页截图：

- 可拉伸锻铁横框和竖框；
- 可拉伸深木/煤黑面板填充；
- 可拉伸羊皮纸标签底；
- 可平铺手牌底纹；
- 黄铜角饰与铆钉点缀；
- 棉纺、制造、陶器、煤矿、炼铁、啤酒六枚原创产业徽章；
- 贸易商啤酒与奖励的原创小型装饰符号。

发光、禁用蒙层、当前玩家脉冲和描边继续用代码生成，避免将交互状态固化进位图。贴图提供 1x/2x/3x 或足够高分辨率的单源图，并通过 cap inset 或平铺方式适配不同尺寸。

## 对局布局

### 顶部状态带

- 将当前两层“房间/同步 + 胶囊统计”合并为一条连续的锻铁状态带。
- 左侧显示时代与回合，中间固定显示当前玩家和行动 1/2，右侧显示牌库、资金、收入、VP 和同步状态。
- 房间号降为次要信息，只在空间充足的 iPad 显示；iPhone 通过辅助功能和详情入口保留。
- 当前玩家状态不再依赖独立浅色胶囊：本机回合使用黄铜底和轻微光晕，等待时使用对应玩家颜色标记。
- 顶栏目标高度：iPhone 44pt，iPad 46–50pt；地图只排除实际顶栏高度。

### 左侧玩家轨

- iPhone 保留 44pt 边缘按钮和现有“点一次展开、再点一次关闭”的抽屉交互。
- 收起态显示玩家颜色/形状、顺序和当前玩家黄铜/绿光指示，不展示大块空白。
- 展开抽屉使用深木底和锻铁框，紧凑展示玩家名、资金/支出、连接、主机和本机标记。
- iPad 继续常驻，但宽度从纯文字大面板压缩为紧凑玩家列；市场区仍位于玩家轨下方。

### 右侧产业轨

- iPhone 保留 44pt 边缘按钮与互斥抽屉。
- 收起态只显示六类产业徽章、等级与是否可用；可选产业得到黄铜描边。
- 展开态及 iPad 常驻态使用紧凑的“徽章 + 等级/费用 + 煤铁成本”横条，不再使用大片半透明灰卡。
- 产业徽章是原创图形，同时保留文字/VoiceOver，不能只靠颜色或图案传达类型。

### 底部手牌坞

- 保留 iPhone 92pt 遮挡预算和现有地图相机边距，避免底部城市重新被手牌挡住。
- 视觉上取消覆盖整个底部的大灰板，改为中央深色手牌坞，两侧留出地图可见区域。
- 手牌继续重叠排列；未选中牌只露出图标、短名和顶部识别色，选中牌上抬并显示黄铜高光。
- iPad 手牌高度不增加；最大卡宽和间距继续由 `HandView.layout` 自适应。

### 地图与贸易商

- 不改变地图拓扑、坐标、缩放、拖动、路线时代逻辑和权威目标 ID。
- 将普通路线从高饱和亮色降低到铁黑/暗蓝；只有当前合法道路才使用明显的绿光。
- 城市、已建产业和贸易商牌提高材质层次，但尺寸和点击区不缩小。
- 贸易商继续在五个市场旁显示接受产业、啤酒和奖励；牌面换成羊皮纸/深木小牌，出售阶段合法目标使用绿光与黄铜边。
- 已建产业使用对应原创产业徽章和玩家色条，保持地图上“一眼看出建了什么”。

## 行动流程

- 选牌后，行动选项仍出现在右下角，但由 2 列大网格改为靠近手牌的紧凑图标条；非法行动显示但明显暗化。
- 进入建造、铺路、出售等步骤后，在手牌上方显示单行上下文条：例如“行动 1/2 · 建造 · 选择城市”；右侧始终保留取消。
- 地图目标是主要入口；底部合法选项保留为辅助/可访问入口，但不与地图目标争夺主视觉。
- 确认面板、强制出售和同步阻塞使用同一套深木/锻铁组件；破坏性操作使用红色，仅在真正需要注意时出现。
- 现有当前回合 1.2 秒转场提示、触觉反馈、VoiceOver 公告和减少动态效果行为保持不变，只更换外观。

## 组件与代码边界

- 扩展 `BrassColor`、`BrassTheme` 与 `BrassComponents`，集中定义工业材质、边框、状态样式和可拉伸贴图入口。
- 新增小型可复用外观组件，例如 `IndustrialPanel`, `ParchmentLabel`, `IndustryMedallion`；不在各业务视图重复贴图、阴影和描边参数。
- `MatchLayoutMetrics` 继续作为 iPhone/iPad 尺寸、遮挡和地图 inset 的唯一来源；视觉重排不得另建一套魔法数字。
- 重构 `MatchHeaderView`、`PlayerRailView`、`IndustryRailView`、`HandView`、`ActionGridView` 和确认/提示面板的外观。
- `AuthoritativeMatchBoardView` 只负责组合和现有交互状态，不把规则或贴图选择逻辑塞入其中。
- `GameMapScene` 只调整渲染层级、颜色与贴图，不改变地图数据、规则端点或目标解析。

## 响应式与可访问性

- iPhone 横屏：44pt 左右触控边，顶部 44pt，底部继续按 92pt 遮挡处理；抽屉互斥且可再次点按关闭。
- iPad 横屏：左右信息轨常驻，不引入手机式折叠；地图仍是最大区域。
- 所有交互目标至少 44pt；装饰图层不接管点击。
- Dynamic Type 下顶栏允许隐藏次要房间号，但时代、行动、当前玩家和资金必须保留。
- 所有生成图作为装饰或与文字并列；VoiceOver 标签、值、选中态和稳定标识继续由代码提供。
- 高光同时使用描边、亮度/形状和文字状态，不能只靠颜色。

## 测试与验收

### 自动化

- 为新增主题 token、资产名称、cap inset 和组件状态增加单元/快照或可检查的纯值测试。
- 更新布局测试，锁定 iPhone 顶栏、44pt 边栏、92pt 手牌和地图遮挡边距；锁定 iPad 常驻侧栏。
- 保留并运行地图目标、贸易商、建造反馈、当前回合和抽屉交互测试。
- 运行完整单元测试、Debug 模拟器构建和 `git diff --check`。

### 双模拟器手动验收

- iPad 建房，iPhone 搜索/加入/准备，房主开始后双方进入同步对局。
- 两台设备分别确认当前玩家清晰、顶栏不裁切、产业/贸易商可辨认。
- iPhone 打开/关闭两侧抽屉，拖动地图并点击最下方城市，手牌不阻断操作。
- 走一轮选牌、建造、铺路或出售，确认上下文条、合法目标、取消和确认状态一致。
- 对比 iPhone 与 iPad 截图，检查贴图没有拉伸接缝、模糊、文字对比不足或过度装饰。

## 非目标

- 不重做首页、房间、设置等非对局页面。
- 不修改规则、地图拓扑、城市位置、玩家人数配置或联机协议。
- 不追求与 Steam 版逐像素一致，也不导入其官方美术。
- 本轮不增加动画特效、粒子系统或音效包；只保留并换肤现有必要反馈。
