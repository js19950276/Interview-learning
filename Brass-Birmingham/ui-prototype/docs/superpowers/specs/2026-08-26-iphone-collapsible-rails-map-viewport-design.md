# iPhone 可折叠边栏与无遮挡地图交互设计

## 目标

让 iPhone 横屏对局中的左右边栏可以点按展开和关闭，并让地图知道底部手牌及两侧边缘按钮占用的空间；顶部状态区继续由现有布局直接排除在地图视口之外。玩家应能通过拖动地图，把当前被手牌遮住的底部城市移动到无遮挡区域并完成点击。iPad 现有常驻边栏保持不变。

## 当前问题与根因

`AuthoritativeMatchBoardView` 始终直接渲染 `PlayerRailView` 和 `IndustryRailView`，没有复用调试对局页已有的手机抽屉交互，因此 iPhone 上只能看到持续覆盖地图的窄边栏，无法展开查看详情或主动关闭抽屉。

`GameMapScene` 的相机边界只依据完整 `SpriteView` 尺寸计算。实际可操作区域被底部手牌和两侧边缘按钮覆盖，但相机不知道这些遮挡；顶部状态区已经通过外层布局从 `SpriteView` 中排除。当相机已经到达地图边界时，底部城市仍可能留在手牌下面，继续拖动会被边界约束吃掉。

## 交互设计

### iPhone 边栏

- 左右各保留现有 44pt 窄栏作为始终可见的边缘按钮。
- 点按左侧按钮展开玩家抽屉；再次点按左侧按钮关闭。
- 点按右侧按钮展开产业抽屉；再次点按右侧按钮关闭。
- 同一时间最多打开一个抽屉。打开另一侧时自动关闭当前抽屉。
- 点击地图空白区域关闭已打开的抽屉；拖动地图不会关闭抽屉。
- 玩家抽屉宽度与现有演示交互一致：视口宽度的 42%，最大 360pt。
- 抽屉避开顶部状态区和底部手牌，并从对应边缘窄栏内侧展开。
- 左侧抽屉显示完整玩家顺序、颜色辅助、连接状态及当前/本机玩家语义；右侧抽屉显示完整产业板块信息。
- 边缘按钮提供“已展开/已收起”辅助功能值，抽屉具有稳定的辅助功能标识。

### iPad 边栏

- 继续显示 220pt 玩家栏和 210pt 产业栏。
- 不增加折叠状态，不改变现有布局、市场位置或交互。

### 地图拖动与遮挡边距

- `GameMapView` 接收地图遮挡边距：顶部、底部、左侧、右侧。
- iPhone 权威对局传入底部手牌及两个 44pt 边缘按钮对应的边距；顶部传零以避免与现有外层布局重复计算。iPad 继续传入零边距，保持现有地图相机行为。
- 展开的临时抽屉不改变相机边界，避免开关抽屉时地图突然跳动。
- 相机继续使用当前语义缩放和地图边界约束，但约束对象改为无遮挡的交互矩形，而不是完整视口。
- 到达地图边缘时，地图边缘允许移动到无遮挡矩形的边缘。因此位于地图最下方的城市可以被拖到手牌上方并点击，同时无遮挡区域内不会露出地图外空白。
- 地图的平移、缩放和目标点击继续共存；在边栏、抽屉和手牌上开始的手势不会传给地图。

## 结构与数据流

### `MapViewportInsets`

新增纯值类型，保存地图相机的 `top`、`leading`、`bottom`、`trailing` 遮挡值。值在进入相机计算前被限制为非负数，并在极小视口下保证剩余互动区域至少为 1pt。

### `MapViewportMetrics`

在现有逻辑尺寸、视口尺寸和语义缩放之外接收遮挡边距，并提供：

- 无遮挡交互矩形的点尺寸；
- 交互矩形中心相对完整视口中心的偏移；
- 基于交互矩形尺寸的相机中心约束；
- 继续沿用当前屏幕点到场景单位的拖动换算。

`GameMapScene.updateViewport` 将尺寸和遮挡边距一起更新。尺寸或边距变化时，返回规范化后的相机位移，防止潜在越界位移在后续缩放时突然出现。

### `AuthoritativeMatchBoardView`

继续使用现有 `MatchInteractionReducer.overlay` 作为唯一抽屉状态，不新增重复布尔值。

- iPhone 的边缘栏变为按钮，调用 `toggleOverlay(.playerRail/.industryRail)`。
- 新增手机抽屉层，根据 `interaction.overlay` 渲染 `PlayerDrawer` 或 `IndustryDrawer`。
- iPad 继续直接渲染完整边栏。
- 地图背景点击继续调用 `interaction.dismissOverlay`；拖动手势不触发该回调。
- 地图遮挡边距由 `MatchLayoutMetrics` 生成，保证布局常量与相机计算使用同一来源。

## 动画与可访问性

- 抽屉使用从对应边缘移动并淡入的短动画；开启“减少动态效果”时只使用淡入淡出。
- 边缘按钮的点击区域不小于 44pt。
- 左右按钮分别使用 `real.playerRail.toggle`、`real.industryRail.toggle`；抽屉分别使用 `overlay.playerRail`、`overlay.industryRail`。
- 按钮辅助功能标签说明用途，值说明当前为“已展开”或“已收起”。
- 地图仍暴露 `match.map`，目标按钮的辅助功能标识不变。

## 测试与验收

### 单元测试

- iPhone 布局指标生成底部和两侧遮挡边距，顶部为零；iPad 返回全零边距以保持现有行为。
- 遮挡边距为负数时会归零；遮挡过大时互动区域仍有效。
- 最小缩放下，相机可以把地图底边移动到手牌上方对应的互动区域边缘。
- 极端拖动仍不会让地图外空白进入无遮挡互动区域。
- 没有遮挡边距时保持现有相机结果，防止预览和既有调用回归。

### UI 测试

- iPhone：左栏点按后出现玩家抽屉，再点按后消失。
- iPhone：打开右栏会关闭左栏，右栏再次点按后消失。
- iPhone：地图纵向拖动后仍可交互，最下方目标可在手牌上方点击。
- iPad：完整左右栏继续常驻，手机抽屉切换按钮不存在。
- iPhone 和 iPad 横屏截图检查无裁切、无手牌/抽屉异常遮挡。

### 回归验证

- 运行地图与布局指标单元测试。
- 运行权威对局 iPhone/iPad UI 测试。
- 运行完整单元测试和双模拟器房间冒烟测试。

## 非目标

- 不折叠或重做底部手牌。
- 不改变 iPad 常驻边栏。
- 不改变地图拓扑、城市坐标、路线时代样式或规则判断。
- 不在抽屉展开时自动缩放或移动地图。
